# 📚 Alura Books

Uma landing page responsiva desenvolvida como parte do curso da **Alura**, aplicando conceitos de **HTML**, **CSS** e **JavaScript**.  
O projeto simula uma vitrine online de livros com carrosséis interativos, banners e seções dinâmicas.

👉 [Link do projeto hospedado:

## 📂 Estrutura do Projeto

```
├── .gitattributes      # Configuração de normalização de arquivos
├── LICENSE             # Licença do projeto
├── index.html          # Estrutura principal da página
├── reset.css           # Reset de estilos
├── styles/
│   └── style.css       # Estilização principal
└── images/             # Imagens utilizadas no projeto
```

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** → Estrutura semântica da aplicação  
- **CSS3** → Estilização e responsividade  
- **JavaScript** → Interatividade e carrosséis  
- **[Swiper.js](https://swiperjs.com/)** → Biblioteca para criação dos sliders  

---

## ✅ Funcionalidades

- Menu de navegação responsivo  
- Campo de busca para explorar livros  
- Carrosséis com lançamentos e mais vendidos  
- Seção de destaques e recomendações  
- Formulário para cadastro de e-mail  
- Rodapé com links institucionais e de comunidade  

---

## ⚙️ Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/alura-books.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd alura-books
   ```

3. Abra o arquivo `index.html` diretamente no navegador.  
   *(Opcional: utilize a extensão **Live Server** do VS Code para melhor experiência de desenvolvimento.)*
